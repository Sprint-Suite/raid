# RAID MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-page web app at `/var/www/raid` that turns pasted project notes into a scored, classified RAID log (Risks, Assumptions, Issues, Dependencies) with dependency-conflict detection, matching the design system of the existing 3-app suite.

**Architecture:** Express server on port 3003 serves a static `public/` UI and a single `POST /extract` endpoint. The endpoint calls the Anthropic Messages API with native structured outputs (`output_format: json_schema`), recomputes severity and RAG server-side, and returns the result. The UI is vanilla HTML + CSS + JS, no build pipeline, mirroring sibling apps (scrumpoker, retrospective, signal).

**Tech Stack:** Node.js 18+, Express, Anthropic Messages API with structured outputs, vanilla CSS with custom properties (forest accent `#2E6F4E`), vanilla JS, `node --test` for unit tests, Playwright for E2E. CommonJS modules to match the suite.

**Spec:** `/var/www/raid/docs/superpowers/specs/2026-05-26-raid-ux-design.md` (628 lines, brainstorming-approved 2026-05-26).

// lib/raid.js
//
// Pure logic for RAID extraction. No network, no env, no Express.
// Exports the JSON schema, system prompt, severity/RAG scoring, and
// the server-side reconcile safeguard that overwrites model-produced
// severity/RAG to defend against arithmetic drift.

const RAID_SCHEMA = {
  type: 'object',
  additionalProperties: false,
  properties: {
    risks: {
      type: 'array',
      items: {
        type: 'object',
        additionalProperties: false,
        properties: {
          title:       { type: 'string' },
          description: { type: 'string' },
          owner:       { type: 'string' },
          probability: { type: 'integer', minimum: 1, maximum: 5 },
          impact:      { type: 'integer', minimum: 1, maximum: 5 },
          severity:    { type: 'integer', minimum: 1, maximum: 25 },
          rag:         { type: 'string', enum: ['Red', 'Amber', 'Green'] },
          mitigation:  { type: 'string' }
        },
        required: ['title', 'description', 'owner', 'probability', 'impact', 'severity', 'rag', 'mitigation']
      }
    },
    assumptions: {
      type: 'array',
      items: {
        type: 'object',
        additionalProperties: false,
        properties: {
          title:             { type: 'string' },
          description:       { type: 'string' },
          owner:             { type: 'string' },
          validation_needed: { type: 'string' }
        },
        required: ['title', 'description', 'owner', 'validation_needed']
      }
    },
    issues: {
      type: 'array',
      items: {
        type: 'object',
        additionalProperties: false,
        properties: {
          title:             { type: 'string' },
          description:       { type: 'string' },
          owner:             { type: 'string' },
          severity:          { type: 'string', enum: ['High', 'Medium', 'Low'] },
          suggested_action:  { type: 'string' }
        },
        required: ['title', 'description', 'owner', 'severity', 'suggested_action']
      }
    },
    dependencies: {
      type: 'array',
      items: {
        type: 'object',
        additionalProperties: false,
        properties: {
          title:         { type: 'string' },
          description:   { type: 'string' },
          owner:         { type: 'string' },
          depends_on:    { type: 'string' },
          conflict_flag: { type: 'boolean' },
          conflict_note: { type: 'string' }
        },
        required: ['title', 'description', 'owner', 'depends_on', 'conflict_flag', 'conflict_note']
      }
    }
  },
  required: ['risks', 'assumptions', 'issues', 'dependencies']
};

const SYSTEM_PROMPT = `You are an expert Agile delivery manager building a RAID log from raw project notes. RAID = Risks, Assumptions, Issues, Dependencies. Return data matching the provided schema only.

CLASSIFY each item the text implies:
- RISK: something that MIGHT happen and would harm the project if it did. Future, uncertain.
- ASSUMPTION: something taken as true without proof, which the plan depends on. If wrong, the plan breaks.
- ISSUE: something that HAS happened or is happening now and needs action. Present, certain.
- DEPENDENCY: something this work needs from another team, system, vendor, or task before it can proceed.

The single most common mistake is confusing a Risk (might happen) with an Issue (has happened). Be strict about tense and certainty. If the text labels something a "risk" but it is already happening and causing harm now, it is an ISSUE, not a Risk. Obey the rubric, not the user's wording. Conversely, if something failed in the past but the live concern is that it might recur, that is a RISK about the future recurrence.

FOR RISKS, score using this rubric:
- probability 1-5: 1 = very unlikely, 5 = near certain.
- impact 1-5: 1 = trivial, 5 = project-threatening.
- severity = probability * impact (compute it).
- rag: Red if severity >= 15, Amber if 8-14, Green if <= 7.
- mitigation: one concrete, actionable sentence. Not "monitor the risk". Say what to actually do.

FOR DEPENDENCIES, detect conflicts:
- If two or more dependencies chain or clash (e.g. Item A needs Team X, who are also blocking Item B), set conflict_flag true and explain in conflict_note referencing the other dependency. Otherwise conflict_flag false and conflict_note "".

OWNERS:
- If a person or team is named or clearly implied, use it. Otherwise use "Unassigned". Never invent a name.

GENERAL:
- Only extract what the text genuinely supports. Do not pad the log with invented items.
- A purely reassuring statement (e.g. "budget is fine") is NOT an item. Omit it.
- If a category has no items, return an empty array for it.
- Keep titles short (under 8 words). Descriptions one or two sentences.`;

function ragFromSeverity(sev) {
  if (sev >= 15) return 'Red';
  if (sev >= 8)  return 'Amber';
  return 'Green';
}

function reconcile(data) {
  for (const r of data.risks || []) {
    if (Number.isInteger(r.probability) && Number.isInteger(r.impact)) {
      r.severity = r.probability * r.impact;
      r.rag = ragFromSeverity(r.severity);
    }
  }
  return data;
}

module.exports = { RAID_SCHEMA, SYSTEM_PROMPT, ragFromSeverity, reconcile };
```

// lib/extract.js
//
// The only place network code lives. Calls the Anthropic Messages API
// with native structured outputs and returns the parsed RAID JSON.
// One retry on any failure, then surfaces the error to the caller.

const { RAID_SCHEMA, SYSTEM_PROMPT, reconcile } = require('./raid.js');

const ANTHROPIC_URL = 'https://api.anthropic.com/v1/messages';
const STRUCTURED_OUTPUTS_BETA = 'structured-outputs-2025-11-13';

async function extractOnce(text, { apiKey, model }) {
  const res = await fetch(ANTHROPIC_URL, {
    method: 'POST',
    headers: {
      'content-type': 'application/json',
      'x-api-key': apiKey,
      'anthropic-version': '2023-06-01',
      'anthropic-beta': STRUCTURED_OUTPUTS_BETA
    },
    body: JSON.stringify({
      model,
      max_tokens: 2048,
      system: SYSTEM_PROMPT,
      messages: [{ role: 'user', content: text }],
      output_format: { type: 'json_schema', schema: RAID_SCHEMA }
    })
  });

  if (!res.ok) {
    const detail = await res.text().catch(() => '');
    throw new Error(`Anthropic ${res.status}: ${detail.slice(0, 300)}`);
  }

  const body = await res.json();
  const textBlock = (body.content || []).find((b) => b.type === 'text');
  if (!textBlock) throw new Error('No text block in response');
  return JSON.parse(textBlock.text);
}

async function extract(text, options) {
  try {
    return reconcile(await extractOnce(text, options));
  } catch (err) {
    console.warn('extract attempt 1 failed:', err.message, '- retrying once');
    return reconcile(await extractOnce(text, options));
  }
}

module.exports = { extract };
```

// lib/buildInfo.js
//
// Provides a short build hash for cache-busting static assets.
// Reads package.json version + git commit. Matches sibling-app pattern.

const fs = require('node:fs');
const path = require('node:path');
const { execFileSync } = require('node:child_process');

function normalizeCommit(value) {
  const commit = String(value || '').trim();
  return commit ? commit.slice(0, 12) : null;
}

function readPackageVersion(baseDir) {
  try {
    const pkg = JSON.parse(fs.readFileSync(path.join(baseDir, 'package.json'), 'utf8'));
    return typeof pkg.version === 'string' ? pkg.version : null;
  } catch (_err) {
    return null;
  }
}

function readGitCommit(baseDir) {
  try {
    return normalizeCommit(execFileSync('git', ['rev-parse', 'HEAD'], {
      cwd: baseDir,
      encoding: 'utf8',
      stdio: ['ignore', 'pipe', 'ignore']
    }));
  } catch (_err) {
    return null;
  }
}

function getBuildInfo(baseDir, env = process.env) {
  return {
    version: env.RAID_VERSION || readPackageVersion(baseDir) || 'unknown',
    commit: normalizeCommit(env.RAID_COMMIT || env.GITHUB_SHA) ||
            readGitCommit(baseDir) ||
            'unknown'
  };
}

module.exports = { getBuildInfo, normalizeCommit, readGitCommit, readPackageVersion };
```

// server.js
//
// Express entry. Mounts /extract, /health, /build, and static public/.

const express = require('express');
const path = require('node:path');
const { extract } = require('./lib/extract.js');
const { getBuildInfo } = require('./lib/buildInfo.js');

const PORT = process.env.PORT || 3003;
const API_KEY = process.env.ANTHROPIC_API_KEY;
const MODEL = process.env.RAID_MODEL || 'claude-sonnet-4-5';
const BUILD = getBuildInfo(__dirname);

const app = express();
app.use(express.json({ limit: '1mb' }));
app.use(express.static(path.join(__dirname, 'public')));

app.post('/extract', async (req, res) => {
  const text = req.body?.text;
  if (typeof text !== 'string' || text.trim().length < 10) {
    return res.status(400).json({ error: "Provide 'text' (at least 10 chars) of project notes." });
  }
  if (!API_KEY) {
    return res.status(500).json({ error: 'ANTHROPIC_API_KEY not set on the server.' });
  }
  try {
    const raid = await extract(text, { apiKey: API_KEY, model: MODEL });
    res.json(raid);
  } catch (err) {
    console.error('extract failed twice:', err.message);
    res.status(502).json({ error: 'Extraction failed. Try rephrasing the notes and resubmit.' });
  }
});

app.get('/health', (_req, res) => res.json({ ok: true, model: MODEL }));
app.get('/build', (_req, res) => res.json(BUILD));

app.listen(PORT, () => console.log(`RAID listening on :${PORT} (model ${MODEL})`));
```

function validateShape(data) {
  const problems = [];
  for (const t of TYPES) {
    if (!Array.isArray(data?.[t])) problems.push(`"${t}" missing or not an array`);
  }
  if (problems.length) return problems;

  (data.risks || []).forEach((r, i) => {
    for (const f of ['title','description','owner','probability','impact','severity','rag','mitigation']) {
      if (r[f] === undefined || r[f] === null) problems.push(`risks[${i}] missing "${f}"`);

    checks.push({ label: `count ${t}`, ok: actual === expect.counts[t], detail: `got ${actual}, want ${expect.counts[t]}` });
  }
  const actualRag = sortedField(data.risks, 'rag');
  const wantRag = [...expect.riskRag].sort();
  checks.push({ label: 'risk RAG bands', ok: JSON.stringify(actualRag) === JSON.stringify(wantRag), detail: `got [${actualRag}], want [${wantRag}]` });

  const actualIss = sortedField(data.issues, 'severity');
  const wantIss = [...expect.issueSeverity].sort();
  checks.push({ label: 'issue severities', ok: JSON.stringify(actualIss) === JSON.stringify(wantIss), detail: `got [${actualIss}], want [${wantIss}]` });

  const anyConflict = (data.dependencies || []).some((d) => d.conflict_flag === true);
  checks.push({ label: 'conflict flag', ok: anyConflict === expect.anyConflict, detail: `got ${anyConflict}, want ${expect.anyConflict}` });

  return { checks, passed: checks.every((c) => c.ok) };
}

async function callEndpoint(text) {
  const res = await fetch(ENDPOINT, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ text })
  });
  if (!res.ok) throw new Error(`HTTP ${res.status} ${res.statusText}`);
  return res.json();
}

async function run() {
  console.log(C.bold(`\nRAID harness  ->  ${ENDPOINT}\n`));
  let totalChecks = 0, passedChecks = 0, casesPassed = 0;

  for (const c of CASES) {
    console.log(C.bold(c.name));
    let data;
    try { data = await callEndpoint(c.text); }
    catch (err) {
      console.log('  ' + C.red(`REQUEST FAILED: ${err.message}`));
      console.log(C.dim('  (is the endpoint running and reachable?)\n'));
      continue;
    }

    const shapeProblems = validateShape(data);
    if (shapeProblems.length) {
      console.log('  ' + C.red('SCHEMA / SCORING PROBLEMS:'));
      shapeProblems.forEach((p) => console.log('    ' + C.red('x ') + p));
    }

    const { checks, passed } = evaluate(data, c.expect);
    for (const ch of checks) {
      totalChecks++;
      if (ch.ok) passedChecks++;
      const mark = ch.ok ? C.green('PASS') : C.red('FAIL');
      const detail = ch.ok ? C.dim(ch.detail) : C.yellow(ch.detail);
      console.log(`  [${mark}] ${ch.label.padEnd(22)} ${detail}`);
    }

    const caseOk = passed && shapeProblems.length === 0;
    if (caseOk) casesPassed++;
    console.log('  ' + (caseOk ? C.green('CASE PASSED') : C.red('CASE FAILED')) + '\n');
  }

  console.log(C.bold('Summary'));
  console.log(`  Cases:  ${casesPassed}/${CASES.length}`);
  console.log(`  Checks: ${passedChecks}/${totalChecks}\n`);
  process.exit(casesPassed === CASES.length ? 0 : 1);
}

run();
```

// Single-page state machine for the RAID UI.
// State phases: 'idle' | 'loading' | 'result' | 'error'.

(function () {
  'use strict';

  const MIN_CHARS = 10;
  const MAX_CHARS = 1_000_000;

  // ---------- State ----------
  const state = {
    phase: 'idle',
    currentSample: 0,
    result: null,
    error: null
  };

  // ---------- DOM ----------
  const $ = (sel) => document.querySelector(sel);
  const dom = {
    textarea:    null,
    counter:     null,
    helper:      null,
    generate:    null,
    resultZone:  null
  };

  // ---------- Validation ----------
  function validate(text) {
    const len = text.length;
    if (len < MIN_CHARS) return { ok: false, helper: `Add a bit more content — at least ${MIN_CHARS} characters.` };
    if (len > MAX_CHARS) return { ok: false, helper: 'Too long — please shorten or submit in parts.' };
    return { ok: true, helper: '' };
  }

  function counterClass(len) {
    if (len > MAX_CHARS) return 'input-card__counter--err';
    if (len > MAX_CHARS * 0.8) return 'input-card__counter--warn';
    return '';
  }

  // ---------- Render ----------
  function render() {
    // Char counter
    const len = dom.textarea.value.length;
    dom.counter.textContent = `${len.toLocaleString()} chars`;
    dom.counter.className = `input-card__counter ${counterClass(len)}`.trim();

    // Helper text + Generate enabled state
    const v = validate(dom.textarea.value);
    if (v.ok) {
      dom.helper.classList.add('input-card__helper--hidden');
      dom.helper.textContent = '';
    } else {
      dom.helper.classList.remove('input-card__helper--hidden');
      dom.helper.textContent = v.helper;
    }
    dom.generate.disabled = !v.ok || state.phase === 'loading';

    // Textarea readonly during loading
    dom.textarea.readOnly = state.phase === 'loading';

    // Generate label
    dom.generate.textContent = state.phase === 'loading' ? 'Generating…' : 'Generate RAID';

    // Result zone
    renderResultZone();
  }

  function renderResultZone() {
    // Placeholder: real rendering in Phase 4. Here, just expose the phase.
    if (state.phase === 'idle') {
      dom.resultZone.hidden = true;
      dom.resultZone.innerHTML = '';
      return;
    }
    dom.resultZone.hidden = false;
    if (state.phase === 'loading') {
      dom.resultZone.innerHTML = `
        <div class="loading">
          <div class="spinner" aria-hidden="true"></div>
          <p>Analysing your notes…</p>
        </div>`;
    } else if (state.phase === 'result') {
      // Phase 4 replaces this with the 2x2 grid
      dom.resultZone.innerHTML = `<pre>${JSON.stringify(state.result, null, 2)}</pre>`;
    } else if (state.phase === 'error') {
      dom.resultZone.innerHTML = `<div class="error">${state.error}</div>`;
    }
  }

  // ---------- API call ----------
  async function callExtract(text) {
    let res;
    try {
      res = await fetch('/extract', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ text })
      });
    } catch (_networkErr) {
      return { ok: false, error: "Couldn't reach the server. Check your connection and try again." };
    }
    if (res.status === 502) return { ok: false, error: 'Extraction failed. Try rephrasing or shortening your notes.' };
    if (res.status === 400) return { ok: false, error: 'The AI service rejected the request. This is likely a temporary configuration issue. Please try again.' };
    if (res.status === 429) return { ok: false, error: 'Too many requests. Please wait a moment and try again.' };
    if (!res.ok)             return { ok: false, error: 'Extraction failed. Try rephrasing or shortening your notes.' };
    const data = await res.json();
    return { ok: true, data };
  }

  // ---------- Event handlers ----------
  async function onGenerate() {
    const v = validate(dom.textarea.value);
    if (!v.ok) return;
    state.phase = 'loading';
    state.error = null;
    render();

    const result = await callExtract(dom.textarea.value);
    if (result.ok) {
      state.phase = 'result';
      state.result = result.data;
    } else {
      state.phase = 'error';
      state.error = result.error;
    }
    render();
  }

  function onTextareaInput() {
    render();
  }

  // ---------- Init ----------
  function init() {
    dom.textarea   = $('#notes-textarea');
    dom.counter    = $('#notes-counter');
    dom.helper     = $('#notes-helper');
    dom.generate   = $('#generate-button');
    dom.resultZone = $('#result-zone');

    // Pre-load sample 0
    if (window.RAID_SAMPLES && window.RAID_SAMPLES[0]) {
      dom.textarea.value = window.RAID_SAMPLES[0].text;
      state.currentSample = 0;
    }

    dom.textarea.addEventListener('input', onTextareaInput);
    dom.generate.addEventListener('click', onGenerate);

    render();
  }

  document.addEventListener('DOMContentLoaded', init);
})();

    return String(s ?? '').replace(/\|/g, '\\|').replace(/\r?\n/g, ' ');
  }

  function toMarkdown(raid) {
    const out = ['# RAID Log', ''];

    out.push('## Risks');
    if (!raid.risks?.length) {
      out.push('_No items detected._');
    } else {
      out.push('| Title | Owner | P | I | Sev | RAG | Mitigation |');
      out.push('|---|---|---|---|---|---|---|');
      for (const r of raid.risks) {
        out.push(`| ${mdEscape(r.title)} | ${mdEscape(r.owner)} | ${r.probability} | ${r.impact} | ${r.severity} | ${r.rag} | ${mdEscape(r.mitigation)} |`);
      }
    }
    out.push('');

    out.push('## Assumptions');
    if (!raid.assumptions?.length) {
      out.push('_No items detected._');
    } else {
      out.push('| Title | Owner | Description | Validate by |');
      out.push('|---|---|---|---|');
      for (const a of raid.assumptions) {
        out.push(`| ${mdEscape(a.title)} | ${mdEscape(a.owner)} | ${mdEscape(a.description)} | ${mdEscape(a.validation_needed)} |`);
      }
    }
    out.push('');

    out.push('## Issues');
    if (!raid.issues?.length) {
      out.push('_No items detected._');
    } else {
      out.push('| Title | Owner | Severity | Description | Action |');
      out.push('|---|---|---|---|---|');
      for (const i of raid.issues) {
        out.push(`| ${mdEscape(i.title)} | ${mdEscape(i.owner)} | ${i.severity} | ${mdEscape(i.description)} | ${mdEscape(i.suggested_action)} |`);
      }
    }
    out.push('');

    out.push('## Dependencies');
    if (!raid.dependencies?.length) {
      out.push('_No items detected._');
    } else {
      out.push('| Title | Owner | Depends on | Conflict | Conflict note |');
      out.push('|---|---|---|---|---|');
      for (const d of raid.dependencies) {
        out.push(`| ${mdEscape(d.title)} | ${mdEscape(d.owner)} | ${mdEscape(d.depends_on)} | ${d.conflict_flag ? 'Yes' : 'No'} | ${mdEscape(d.conflict_note)} |`);
      }
    }
    out.push('');

    return out.join('\n');
  }

  function csvCell(v) {
    const s = String(v ?? '');
    if (s.includes(',') || s.includes('"') || s.includes('\n')) {
      return '"' + s.replace(/"/g, '""') + '"';
    }
    return s;
  }

  function csvRow(arr) { return arr.map(csvCell).join(','); }

  function toCSV(raid) {
    const header = ['Type','Title','Description','Owner','Probability','Impact','SeverityScore','RAG','SeverityLabel','Mitigation','Action','Validation','DependsOn','Conflict','ConflictNote'];
    const rows = [header];

    for (const r of raid.risks || []) {
      rows.push(['Risk', r.title, r.description, r.owner, r.probability, r.impact, r.severity, r.rag, '', r.mitigation, '', '', '', '', '']);
    }
    for (const a of raid.assumptions || []) {
      rows.push(['Assumption', a.title, a.description, a.owner, '', '', '', '', '', '', '', a.validation_needed, '', '', '']);
    }
    for (const i of raid.issues || []) {
      rows.push(['Issue', i.title, i.description, i.owner, '', '', '', '', i.severity, '', i.suggested_action, '', '', '', '']);
    }
    for (const d of raid.dependencies || []) {
      rows.push(['Dependency', d.title, d.description, d.owner, '', '', '', '', '', '', '', '', d.depends_on, d.conflict_flag ? 'Yes' : 'No', d.conflict_note || '']);
    }
    return rows.map(csvRow).join('\n');
  }

  function jiraPriorityForRisk(rag) {
    if (rag === 'Red') return 'Highest';
    if (rag === 'Amber') return 'High';
    return 'Medium';
  }

  function jiraPriorityForIssue(severity) {
    if (severity === 'High') return 'Highest';
    if (severity === 'Medium') return 'High';
    return 'Medium';
  }

  function toJiraCSV(raid) {
    const header = ['Summary','Issue Type','Priority','Description','Assignee','Labels'];
    const rows = [header];

    for (const r of raid.risks || []) {
      const desc = `${r.description}\n\nMitigation: ${r.mitigation}\n\nProbability: ${r.probability}, Impact: ${r.impact}, Severity: ${r.severity}, RAG: ${r.rag}`;
      rows.push([r.title, 'Risk', jiraPriorityForRisk(r.rag), desc, r.owner === 'Unassigned' ? '' : r.owner, 'raid-extracted risk']);
    }
    for (const a of raid.assumptions || []) {
      const desc = `${a.description}\n\nValidate by: ${a.validation_needed}`;
      rows.push([a.title, 'Task', 'Medium', desc, a.owner === 'Unassigned' ? '' : a.owner, 'raid-extracted assumption']);
    }
    for (const i of raid.issues || []) {
      const desc = `${i.description}\n\nAction: ${i.suggested_action}`;
      rows.push([i.title, 'Bug', jiraPriorityForIssue(i.severity), desc, i.owner === 'Unassigned' ? '' : i.owner, 'raid-extracted issue']);
    }
    for (const d of raid.dependencies || []) {
      const desc = `${d.description}\n\nDepends on: ${d.depends_on}${d.conflict_flag ? `\n\nCONFLICT: ${d.conflict_note}` : ''}`;
      rows.push([d.title, 'Task', d.conflict_flag ? 'Highest' : 'Medium', desc, d.owner === 'Unassigned' ? '' : d.owner, 'raid-extracted dependency']);
    }
    return rows.map(csvRow).join('\n');
  }

  window.RaidExports = { toMarkdown, toCSV, toJiraCSV };
})(window);
```

  let heartbeatTimer = null;

  function clearHeartbeat() {
    if (heartbeatTimer) {
      clearTimeout(heartbeatTimer);
      heartbeatTimer = null;
    }
  }

  function startHeartbeat() {
    clearHeartbeat();
    heartbeatTimer = setTimeout(() => {
      if (state.phase !== 'loading') return;
      const loadingEl = dom.resultZone.querySelector('.loading p');
      if (loadingEl) loadingEl.innerHTML = 'Analysing your notes…<br><small>This is taking a bit longer than usual…</small>';
    }, 20_000);
  }

  async function onGenerate() {
    const v = validate(dom.textarea.value);
    if (!v.ok) return;
    state.phase = 'loading';
    state.error = null;
    render();
    startHeartbeat();

    const result = await callExtract(dom.textarea.value);
    clearHeartbeat();
    if (result.ok) {
      state.phase = 'result';
      state.result = result.data;
    } else {
      state.phase = 'error';
      state.error = result.error;
    }
    render();
  }
